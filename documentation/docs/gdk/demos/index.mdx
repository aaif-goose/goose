# Demos

A personal wiki, a phone-call assistant, a voice interface, and more.
Explore what these applications do, then look inside to see how they work.

Some embed GDK components directly. Others build on the pre-built goose agent
over [ACP](/docs/gdk/acp). Each demo explains which approach it takes and the
design choice worth borrowing for your own application.

# goose grant program

The goose Grant program is now administered by [Spiral](https://spiral.xyz/). Spiral's mission is to support open money and open intelligence as open source public goods.

To submit a grant application to work on open source AI, please visit [Spiral's Grants page](https://spiral.xyz/grants/).

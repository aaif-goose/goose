# oi-kit-sdk

Python bindings for the Open Intelligence Kit (oi-kit).

This package is generated from the Rust `oi-kit-sdk` crate using UniFFI.

## Build a local wheel

From the repository root:

```bash
just --justfile crates/oi-kit-sdk/justfile python-wheel
```

The wheel is written to `crates/oi-kit-sdk/python/dist/`.

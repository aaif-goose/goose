# hello-sidecar

Demo GRC client extension for the **sidecar** extension point.

## Contributions

- **sidecar** (`session-info`) — a right-side panel on the chat route showing session context from the host.

## Try it

When running goose Desktop from source, this extension is auto-discovered from `examples/client-extensions/`.

Open a chat (`/pair`), click the panel icon in the top-right, and view the active session ID.

# hello-page

Example GRC client extension with a **rootLink** — adds a sidebar item and renders this HTML in the main content area.

Route: `/ext/hello-page/home`

Copy to install:

```bash
mkdir -p ~/.agents/client-extensions
cp -R examples/client-extensions/hello-page ~/.agents/client-extensions/
```

Restart goose Desktop and open **Hello Page** from the sidebar.
